一句话：改造前 → 改造后

改造前

  • 记忆只有 KV：set/get/all，存不进语义、跨会话只能精确取键
  • 一次 429 / 超时 → 整个 agent 失败，没有重试
  • durable 只覆盖 complete(文本) + ask_human，其余调用重放就重复扣费
  • 没有任何输入/输出安全校验（注入 / PII / 越权裸奔）
  • 改了 agent 代码无法跑回归打分，没有安全网
→

改造后

  • 语义召回 hybrid（向量+BM25+rerank）+ 结构化工作记忆自动注入 + 对话压缩
  • 瞬时退避重试贯穿 complete / stream / 工具循环（@agent(retries=N)）
  • durable 全覆盖：kb/media/结构化/子 agent/流式/工具循环逐步可重放，崩溃恢复不重执行
  • guardrails：注入拦截 / PII 脱敏 / 长度 / 输出 schema（block/redact/retry/warn）
  • agentkit agent 当被测对象，跑数据集 → judge 打分 → 版本对比闭环

平台内置 · 代码优先 · 内部 SDK

agentkit 能做什么

写一个 @agent + async def handle(ctx)，平台隐式接管 模型 / 知识库 / 工具 / 记忆 / 子智能体 / 多模态 / 追踪 / 计费 / 互操作。 同一份代码，换 transport 即换运行环境——本机自测 → 站内运行 → 沙箱隔离，零改动。

核心能力

对话 / 流式

基础

单模型一问一答或流式输出，平台注入模型、自动 trace + 计费。

async for chunk in ctx.stream(user=ctx.query):
    yield chunk

RAG 知识检索

能力

hybrid 召回 + rerank + 查询扩展，自动 citation 进 trace。

hits = await ctx.kb.search(ctx.query, rerank=True)
ctx.stream(system=f"依据：{hits}", user=ctx.query)

工具调用 ReAct

能力

模型自主决定调哪些工具、循环到收敛，含并行调用 + token 预算闸。

async for d in ctx.run_with_tools(user=ctx.query):
    yield d   # 平台工具 + 本地 @tool

多智能体编排

能力

并行扇出 gather / 路由 route / 移交 handoff，预算均分 + 深度限制。

a, b = await ctx.gather([("researcher", q),
                          ("writer", q)])

MCP 双向互操作

旗舰

消费外部 MCP server 的工具；自家 agent 也可暴露为 MCP server（stdio/http/sse）。

@agent(mcp_servers=[McpServerConfig(
    name="math", url="http://localhost:9100/mcp")])

开放 A2A 跨系统

旗舰

调远程 Agent2Agent（对齐 Google A2A）；自家 agent 经 /a2a/{key} 暴露给外部客户端。

remote = await ctx.call_agent(
    "https://partner/a2a/their-agent", input=q)

人在环 / 可恢复 (durable)

旗舰

高风险动作前暂停等人工批准，恢复后继续；journal 重放、进程重启不丢、防决策翻转。

@agent(durable=True)
decision = await ctx.ask_human("批准删库？")

不可信代码沙箱

旗舰

陌生人代码 docker 隔离：--network none --read-only + scope 鉴权 + fail-closed。

@agent(sandboxed=True, trust_tier="untrusted")

多模态生成

能力

文生图 / 图生图，产物存 MinIO + 计费归集；本地 ComfyUI 或远程 DashScope。

r = await ctx.media.generate(kind="image", prompt=q)
yield f"![]({r.url})"

结构化输出 / 记忆

能力

返回严格 schema 的 Pydantic 实例；跨会话 kv 记忆。

p = await ctx.complete(user=q, schema=Person)
await ctx.memory.set("last", p.name)

运行三态（同一份 handle 代码）

STANDALONE

本机脱平台

装 SDK + 自带 key，StandaloneTransport 本机跑，不连平台——作者快速自测。

DEV

连 dev 服务

agentkit dev/chat 经 HttpDevTransport 回调站内资源；改文件热重载重跑。

IN-PROCESS

站内进程内

提交进 chameleon-agents/ 自动发现，InProcessTransport 进程内运行。

SANDBOX

docker 隔离

不可信代码经 SandboxTransport 在隔离容器跑，broker 守 scope 红线。

⚠️ 前端「应用详情 / 设置」覆盖现状

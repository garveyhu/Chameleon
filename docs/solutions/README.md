# 解决方案库（Solutions）

可复用的方案沉淀。和 `docs/plans/`（一次性、带日期的实施计划）不同，这里收的是**遇到同类问题下次直接照搬**的通用方案——架构模式、子系统设计、踩坑的根因与解法。

每条方案文档应说清：**何时翻它**（适用场景）、**核心机制**（图 + 流程）、**怎么复用/扩展**、**取舍与已知限制**。
